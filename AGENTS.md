# Инструкции для работы над AstraTerm

Перед изменениями прочитай [agent.md](agent.md) — это основной документ с правилами проекта.

Общие изменения по умолчанию реализуются одновременно в Linux и Windows. Короткий рабочий контекст — [docs/CONTEXT.md](docs/CONTEXT.md); единая версия и параметры — `shared/product.json`.

Фактические возможности описаны в [docs/FEATURES.md](docs/FEATURES.md), оставшаяся работа и критерии приёмки — в [docs/ROADMAP.md](docs/ROADMAP.md). Запланированные функции не считать реализованными.
