# Сравнение Linux и Windows

В 0.9.1 в ПКМ по вкладке добавлены дублирование всех её соединений и переподключение. Переподключение использует актуальные сохранённые параметры; форма явно показывает выбранный SSH-ключ, а Windows-обзор переключает на собственный файл. [Поведение и проверки](TAB_SESSION_ACTIONS.md).

Общий релиз **0.10.0**, формат сессий **2**. Linux ранее имел номер 0.4.0; он выровнен с Windows через `shared/product.json`. Номер продукта общий, но доступность системных функций различается. Полного паритета с MobaXterm нет.

Обновления: общий подписанный stable-feed, HTTPS и SHA-256; Windows заменяет portable EXE с backup/перезапуском, Linux устанавливает DEB через системный установщик с последующим явным перезапуском. ZIP/dev Windows скачивает portable без замены многокомпонентного каталога. [UPDATES.md](UPDATES.md).

## Политика развития

Новые общие функции и изменения дизайна выполнять в обеих версиях в одной задаче. Временное расхождение явно отмечать здесь/в FEATURES и плане, а не оставлять молчаливый порт. ОС-исправление может затронуть только один адаптер, но должно сохранять общий контракт. Наличие профиля протокола в экспорте не означает работающий клиент.

Номер 0.5.0 в Linux не означает перенос Electron туда или завершение отсутствующих Windows-протоколов. В этой задаче унифицированы release metadata, общие данные, тестовые контракты и сборка; функциональные отличия в таблице сохранены честно.
