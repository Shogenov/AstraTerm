# Основной сайт

`template.html` содержит шаблон главной страницы и ссылку на репозиторий GitHub. `tools/website_build.py` подставляет иллюстрации, сведения о платформах и ссылки скачивания. На `assets/windows-app.png` и `assets/linux-app.png` показаны демонстрационные сессии AstraTerm с тестовыми данными.

`python tools/website_build.py` собирает `dist/`. Для финальных ссылок, SHA-256 и разных версий ОС передайте `--metadata` с проверенным открытым payload релиза; при `-Deploy` сборщик делает это сам. Файлы `assets/screenshots.css` и `site.js` добавляют переключение снимков Windows/Linux и сохраняют мобильную компоновку.

Три прежние концепции сборщик копирует под `alternatives/`. Деплой публикует публичный HTML, ресурсы и код панели. Порядок публикации и контракт приложения описаны в [UPDATES.md](../../docs/UPDATES.md).

## Статистика сайта

Панель `/admin/` работает на PHP 8.3 и читает журналы доступа хостинга. На дашборде есть итоги и графики по дням, фильтры «Сегодня», «7 дней», «30 дней» и «Вся история», а также отдельная строка для каждого пакета из `/releases/`.

- Просмотры учитываются для главной и альтернативных страниц. Визит оценивается по адресу и браузеру с интервалом без просмотров в 30 минут. Известные роботы отфильтровываются. Для сбора статистики не нужны счётчики, cookies или MySQL.
- Полное скачивание учитывается, когда GET с ответом HTTP 200 передал весь файл. Ответы 206 и неполные ответы 200 показаны отдельно. Журнал не позволяет определить, собрался ли целый файл из нескольких запросов 206. Прямые ссылки и обновлятор учитываются по одним правилам.
- Доступная история зависит от текущего журнала и десяти ротаций. При чтении действует предел в 16 МиБ распакованных записей. Панель показывает даты доступных данных и предупреждает при неполном чтении.

Хеш отдельного пароля хранится в `/.astraterm-analytics/auth.json` в корне аккаунта хостинга, вне каталога сайта. Публикация релиза сохраняет этот файл. Команда `./tools/site-admin-password.ps1` копирует пароль в буфер обмена из хранилища DPAPI. Запускайте её на том же ПК и под той же учётной записью Windows, где пароль был настроен. Скрипт находит файл `AstraTermBuild/site-admin.dpapi` в системной папке Local AppData текущего пользователя.

Если локальное хранилище недоступно, запустите `python tools/site_admin_reset.py --host <FTPS-сервер> --user <FTPS-логин>` в терминале. Скрипт запросит пароль FTP и новый пароль панели со скрытым вводом. При успешной замене хеша войдите на `/admin/` с новым паролем. Активные сессии панели завершатся при следующем запросе. Сохраните новый пароль в менеджере паролей.

Для проверки подсчёта на синтетических журналах запустите `php tests/site_statistics.php` из корня проекта.
