# Варианты сайта AstraTerm

Три самостоятельные адаптивные страницы для выбора дизайна:

1. Graphite — графит и мята, визуальное продолжение приложения.
2. Paper — светлый редакционный стиль и крупная типографика.
3. Signal — контрастный синий, лайм и акцент на работе с несколькими хостами.

`dist/index.html` — сравнение, `dist/{graphite,paper,signal}/index.html` — страницы. Все тексты о возможностях основаны на `docs/FEATURES.md`; терминалы на страницах — иллюстрации с вымышленными данными. Интерактивный пример MultiExec не подключается к серверам и не исполняет команды.

Сборка: `python website/design-previews/build.py`. Предпросмотр: `node website/design-previews/preview.cjs`, затем напечатанный Local URL. Сервер слушает только loopback и обслуживает только `dist/`; отдельный allowlist разрешает скачать две уже собранные версии приложения. Версия берётся из `shared/product.json`.

Варианты предназначены для согласования. Основной сайт, DNS, хостинг и MySQL пока не изменены. Доступы к хостингу в файлах проекта не хранятся. После выбора требуется подготовить один production-каталог и загрузить его на предоставленный пользователем хостинг. Для этого сайта отдельная база данных не нужна.

Шрифты Onest, IBM Plex Mono и Prata скачаны с Google Fonts и хранятся локально, без внешних запросов посетителя. Их лицензии SIL Open Font License включены в `assets/LICENSE-*.txt`. Обновление файлов шрифтов: `python website/design-previews/fetch_fonts.py`. При недоступности используются системные гарнитуры.

Статический архив находится в `artifacts/website/astraterm-design-previews.zip`: распакуйте и откройте `index.html`. Переходы между концепциями и интерактивный пример работают также без сервера; скачивание приложения доступно через локальный HTTP-предпросмотр. Архив не содержит бинарников приложения.

Правки: тексты и разметка — `build.py`; общая сетка и компоненты — `styles/base.css`; оформление каждой концепции — одноимённый CSS; поведение демонстрации — `assets/site.js`. После изменения запустите сборку и обновите страницу. Снимки проверки — `artifacts/website/*-desktop.png` и `*-mobile.png`.
